# Fast Media Communications — 4K Broadcast Equipment & Camera Rental Service

A modernized, high-performance web application for **Fast Media Communications**, South India and Mumbai's premier provider of native 4K broadcast multicam equipment, telephoto box lenses, and turnkey production engineering. Founded by **Mr. G. Sundaresan** with over three decades of broadcast mastery.

---

## 🌟 Key Highlights & Features

- **Executive Corporate Design**: Sleek Sapphire Blue & Slate aesthetic with high-contrast typography, interactive cyan magnetic cursor, and smooth scroll reveal animations.
- **Full Equipment Inventory Fleet**: Interactive filter tabs for Multicam Cameras (Sony HDC-3200 4K, HDC-1700, HSC-100), Telephoto Box Lenses (Canon 111X, 90X, 86X, Fujinon 76X), Cine Primes & Zooms (Zeiss CP3, Sony FX9, Angenieux HR), Switchers, Matrix Intercoms (RTS ODIN), and Studio Pedestals.
- **Real Production Portfolio**: Highlighting blockbuster live audio launches (*Varanasi*, *Idly Kadai*, *Madharaasi*, *Retro*) and mega arena conventions (*TVK Maanadu*, *Murugan Maanadu*).
- **Official Channel Partners Showcase**: High-resolution logos of premier networks including Sun TV Network, Zee Tamil, Zee Kannada, Star Vijay, Colors TV / Tamil, Jaya TV, Kalaignar TV, News7 Tamil, Vision Time, and Wave Media.
- **Instant Inquiry & WhatsApp Dispatch**: Pre-fills and redirects inquiries directly to 24/7 technical dispatch with shoot details.
- **Pan-India Hubs Locator**: Direct click-to-dial and map details for Chennai HQ, Mumbai Regional Center, and Hubs in Bangalore, Hyderabad, Kochi, and Trivandrum.

- **Core**: HTML5, Vanilla JavaScript (ES6 Modules)

- **Build Tool**: [Vite](https://vitejs.dev/)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/SubilinGreety/Fast-Media-Communications.git
   cd Fast-Media-Communications
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
